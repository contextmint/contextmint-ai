ContextMint CLI

Automate indexing, health checks, and graph queries in CI and platform scripts — the same operations available in the VS Code extension.

Common commands

# Check backend health
contextmint health --url http://localhost:8000

# Trigger workspace reindex
contextmint index --workspace ./my-repo

# Query blast radius (JSON output)
contextmint blast-radius --target services/payments-api

# Build context pack
contextmint pack build --name architecture
  • JSON output for CI pipeline integration
  • Exit codes aligned with gate scripts (GATE-AHA, GATE-IMPACT)
  • Configurable via environment variables — no hardcoded endpoints
  • Early access — request demo for CLI package distribution
