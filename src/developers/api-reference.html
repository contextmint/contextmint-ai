REST API

API reference

FastAPI backend served locally by default. OpenAPI schema available at /docs when the server is running.

Core endpoints

GET /api/health

Server and dependency health check.

POST /api/search

Hybrid BM25 + vector retrieval with workspace scoping.

GET /fabric/explain

Blast radius and impact explanation with evidence paths.

POST /fabric/correct

Human correction — sets verification_status to verified.

POST /fabric/propose

Queue proposed graph mutations for review.

GET /api/packs/*

Context pack builder, sync, and manifest APIs.

GET /api/actions/stats

Acceptance and proposal statistics for governance dashboards.

Interactive docs

Start the local server and open Swagger UI for the full schema, request bodies, and response models.

uvicorn main:app --reload --port 8000
# → http://localhost:8000/docs
