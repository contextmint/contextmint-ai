TRUST CENTER

Built for teams who cannot afford silent failures

Local-first by default. Deterministic graph truth. Audit everything. Enterprise controls when you need them.

Local-first architecture

Code indexing, embeddings, and retrieval run on your infrastructure. Ollama processes locally — source never required to leave your device on the Developer tier.

Deterministic verification

Blast radius, drift, and scorecard metrics are graph-computed — not LLM guesses. AI assists narration; graph evidence is authoritative.

RBAC & agent governance

Role-based access for humans and MCP agents. Policy engine enforces what agents can read and propose. No silent writes — user confirms each step.

Audit trail

Actions, fabric proposals, and acceptance stats logged for compliance review. Export-ready for SOC 2 and internal security audits.

Enterprise deployment options

  • SSO via SAML / OIDC (Enterprise)
  • Self-hosted server mode for team sync
  • Air-gapped Helm chart for regulated environments
  • Tenant isolation with tenant_id / owner_id on graph entities
  • Evidence ledger with verification_status per fabric edge

SOC 2 Type II and formal compliance packaging are on the Enterprise roadmap. Contact us for security questionnaires and architecture review sessions.
