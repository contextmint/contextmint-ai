Settings reference

ContextMint settings live in VS Code Settings (search “ContextMint”) and in Engine Settings for operator paths. Values below use the contextmint.* namespace.

Server & connectivity

  • contextmint.server.serverUrl — API base (default http://localhost:8000)
  • contextmint.server.serverTimeoutMs — health / request timeout
  • contextmint.server.autoStart — extension dev helper only; packaged mode uses Engine

Chat

  • contextmint.chat.defaultModel — Auto | local | cloud
  • contextmint.chat.placement — side panel vs editor placement
  • contextmint.chat.maxHistorySend — messages included in stream body
  • contextmint.chat.reasoningCollapseOnAnswer — collapse reasoning panel when answer starts
  • contextmint.chat.cloudThinkingEnabled — extended thinking for supported cloud models

Context lanes

  • contextmint.chat.contextLanesEnabled — show Repo / Work / Hybrid selector
  • contextmint.chat.defaultContextLane — repo | work | hybrid
  • contextmint.chat.repoLanePlaceholder — compose hint for Repo lane
  • contextmint.chat.workLanePlaceholder — compose hint for Work lane
  • contextmint.chat.hybridLanePlaceholder — compose hint for Hybrid lane
  • contextmint.chat.laneSuggestEnabled — banner when repo retrieval is weak
  • contextmint.chat.laneSuggestPrompt — banner text
  • contextmint.chat.laneSuggestWorkButtonLabel — retry button label

Trust & preview

  • contextmint.trust.trustGateEnabled — extra confirm on sensitive sends
  • contextmint.trust.lensPreviewEnabled — Context Lens before inference
  • contextmint.trust.lensPreviewFirstNSends — auto-preview for first N sends per session
  • contextmint.trust.cloudEnabled — allow cloud tier in routing
  • contextmint.trust.enterpriseMode — OIDC / shared server auth path

Packs

  • contextmint.packs.autoSync — debounced rebuild on source changes
  • contextmint.packs.syncDebounceMs — debounce interval

Image evidence & ARGUS

  • contextmint.chat.imageAttachmentsEnabled — paste / drop / picker for screenshots
  • contextmint.chat.imageMaxCountPerMessage — max images per send (default 3)
  • contextmint.chat.imageMaxBytes — per-image size cap (default 5 MiB)
  • contextmint.chat.imageSensitivityNotice — first-attach privacy notice text
  • contextmint.chat.pullVisionModelPrompt — CTA when no local VLM installed
  • contextmint.chat.cloudVisionOptInHint — secondary hint for optional BYOK vision
  • contextmint.argus.auditButtonLabel — Lens action label (default “Run visual audit”)

Server-side tunables (chat.image_*, argus.enabled, argus.vlm_model, …) live in operator defaults on the API host. See Image evidence & ARGUS.

Inline completion (optional)

  • contextmint.inline.enabled — ghost text completions
  • contextmint.inline.pauseWhileIndexing — reduce load during bulk index
  • contextmint.inline.yieldToChat — defer inline when chat is streaming

Backend defaults (operators)

Server tunables live in contextmint.defaults.yaml on the API host — chat token caps, lane suggest thresholds, indexing concurrency, etc. Engine Settings exposes a subset; full list is in the operator repo documentation for self-hosted deployments.
