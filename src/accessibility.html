Accessibility

Last updated: 22 July 2026

Commitment

ContextMint Ltd aims for the public marketing website at {{ site.url }} to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

This statement covers the marketing site only. It does not cover the ContextMint VS Code extension, desktop Engine, or customer-hosted API deployments.

Measures we take

  • Semantic HTML landmarks, labelled navigation, and skip-to-main-content
  • Keyboard support for menus, dialogs, carousels, and forms
  • Visible focus indicators and minimum target sizes for primary controls
  • Colour contrast targets for body text and primary calls to action
  • Optional select-to-speak for reading highlighted page text
  • Automated axe checks on key pages in continuous integration after site build

Conformance status

The site is designed to conform to WCAG 2.2 Level AA. This is not a claim of third-party certification. Known limitations and remediation history are tracked in the site repository accessibility audit notes.

Known limitations

  • Screenshot carousels rely on keyboard focus within the carousel region; autoplay pauses when the region is focused or when reduced-motion preferences are set.
  • Select-to-speak uses the browser Web Speech API; voice quality and language coverage depend on the visitor’s operating system and browser.
  • Some dense documentation pages may still contain long tables or code samples that benefit from further readability review.
