Frequently asked

Does my code leave my machine on the Developer tier?

No. Indexing, embeddings, and chat run locally via Ollama. Cloud routing is opt-in on higher tiers.

What happens after the Team trial?

Continue on Team or downgrade to Developer local-only. No silent charges — you confirm before billing starts.

Is Enterprise required for MCP and agents?

MCP read tools are available on Team. Agent write governance, policy engine, and audit export are Enterprise.
