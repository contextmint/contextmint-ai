v1.0 foundation

Local-first decision-control plane for software teams — evidence before inference, human approval before repo changes. Design partners run this today; general availability August 2026.

  • ContextMint Engine — tray-native operator console (server, Ollama, models, indexing, quality scans, logs, support bundle)
  • VS Code extension — Ask / Plan / Agent modes, chat sessions, attach context, suggested prompts
  • Context Lens (gate 1) — preview retrieved chunks, scores, routing, and governance notes before the model runs
  • Patch preview (gate 2) — review unified diffs before anything applies; no silent writes
  • Quality map — stored governance findings (clones, near-duplicates, structure signals) with optional apply gates
  • Context packs — per-repo manifests with @pack:name activation and auto-sync
  • Glass-box routing — provenance breakdown, routing badge, reasoning trace for power users
  • Conventions learner — proposals and audit history with human approval before rules enter the graph
  • Local-first default — Engine + Ollama on loopback; code stays on device

Optional (off by default): BYOK cloud routing, git sandbox worktrees, inline completion, shared on-prem API server for enterprise pilots — full v1.0 list.

Planned direction

Verification Engine

Capabilities that build on the v1.0 foundation — deterministic graph evidence first; AI narrates with citations, never overrides graph truth without human confirmation. Order and timing evolve with design partner feedback; no public quarters until after v1.0 GA.

  • PR verification gates — ownership, impact, and policy checked on every change (vision)
  • Blast radius — graph traversal for impacted services, files, and teams (learn more)
  • Repository DNA — deterministic repo health and convention baselines (learn more)
  • Decision graph — architecture intent and ADR traceability (learn more)
  • Drift detection — scorecards for accepted vs violation baselines (learn more)
  • Agent governance — policy-scoped tool contracts for AI agents in CI (learn more)
  • Enterprise SSO (OIDC) and workspace RBAC on shared server deployments
  • SOC 2 evidence packaging — formal compliance collectors (enterprise roadmap)
  • Enterprise CLI packaging — graph queries and verification in CI pipelines
  • MCP server for agents — blast radius, features, and decisions as tool contracts (contracts)
